# 模板 09 · 调研 / 可行性时间盒（Spike）

> 适用：不确定能不能做、怎么做、值不值得做；需要先调研再决策。
> 原则：**时间盒 + 明确交付物（决策备忘）+ 不改生产**。

---

## 1. 问题（Question）
- 要回答的**一个**决策问题（不要多个混在一起）。
- 为什么现在要回答；不回答会阻塞什么。

## 2. 时间盒（Timebox）
- 投入上限：____ 小时/天；硬截止：____。
- 到期未得出结论也要交付"当前最佳判断 + 还缺什么"。

## 3. 范围与非范围
- 可查：官方文档/源码/实验/访谈/竞品；**不改生产代码/数据**。
- 不做：完整实现、长期优化、与决策无关的探索。

## 4. 方法
- 信息源与优先级（官方 > 一手实验 > 二手）。
- 实验设计（如需要）：最小验证、对照、成功判据。
- 记录方式：结论 + 证据链接 + 日期。

## 5. 交付物（Decision Memo）
```markdown
# 决策备忘：____
## 结论（一句话）
## 依据（3-5 条，附来源/实验证据）
## 选项对比（A/B/不做）
## 风险与未知
## 建议下一步（做/不做/再调研）
```

## 6. 完成定义
- 有明确建议（做/不做/条件性做）+ 依据 + 风险 + 下一步。
- 未验证/无法查证的项已标注。

## 7. 常见错误
- 调研变成"实现"（提前写代码）。
- 没有时间盒，无限探索。
- 只收集资料不做判断（没有结论）。
- 引用营销内容当证据；不标来源与日期。

## 8. 最小可用版

```text
【问题】____
【时间盒】____ 小时内
【可查】官方文档/源码/最小实验；不改生产
【交付】决策备忘：结论 + 3 条依据 + 风险 + 建议
【停点】查到能下结论就停，不要扩展
```
