通用人机协作协议（CGE v1.1）一页速查

长图

答

结论

把任务交给 Agent 时，只做三件事：先签契约、按风险过闸、用证据验收；这样"完成"才可复现。

  1. 契约用 14 个必填字段 + 6 个条件字段，写清目标、范围、验收、授权。
  2. 风险分 R0–R3：R0 走轻量闸，R3 过全部闸门、独立复核并备好回滚。
  3. 验收最低 E2：命令 + 原始输出 + 退出码；"已完成"这类自述（E0）不算。
  4. 每次踩坑把规则写进 AGENTS.md、README 或技能（G6），下次会话不用重讲。

适用于依据《通用人机协作协议（CGE v1.1）》§0、§2–§4、§6、§11；适用新需求、缺陷、改进重构、审查、发布、调研与文档任务。

1

任务契约要写清哪 20 个字段？

四件产物按时间出现：任务契约、方案与决策记录、验收证据报告、交接与规范。没有落成文件的结论，视为没有发生。

意图背景与证据、目标、受众与场景、成功度量验收标准不可判定
边界范围 In、非范围 Out、约束、权威源、假设与未知、风险与不可逆点非范围留空
交付交付物、验收标准、证据等级、质量门槛、批次与里程碑、依赖与时间未写证据等级
协作授权边界、流程模式、报告格式、停点与升级授权没有按动作拆

六道闸门各自卡什么？

G0–G5 是六道闸门，G6 是收尾的"沉淀闸"。

闸门一句话问题通过标准谁批
G0 基线规范、现状、权威源、冲突点清楚吗？事实快照 + 未知清单 + 冲突裁决人（或 Agent 显式列假设）
G1 契约目标、范围、验收、授权明确吗？契约复述 + 评分达标 + 关键问题已答人
G2 方案怎么做、影响多大、怎么回滚？至少 2 个选项或说明无备选的理由 + 风险 + 回滚人（R2+）
G3 执行是否小步执行、变更受控？里程碑报告；范围变化即停Agent 自主 + 人抽检
G4 验收每条验收都有证据吗？验收矩阵 + 证据等级达标 + 未验证项人
G5 发布现在可以对外或不可逆生效吗？明示授权 + 回滚就绪 + 发布后核对人
G6 沉淀规则、文档、交接更新了吗？规范回写 + 交接词 + 复盘人/团队
3

风险等级怎么定闸门密度？

等级判定必过闸门最低证据
R0 低局部、无外部可见变化、可秒回滚G1 轻 + G4E1（有外部可见变化时 E2）
R1 一般单模块或单文件、影响可控G1 + G4；G2 可选（≥2 文件或有取舍时）E2
R2 较高跨模块、接口、数据、批量、对外内容、版式G0 + G1 + G2 + G3 + G4；发布时加 G5E2 + 关键项 E3
R3 高生产发布、不可逆、安全、法务、资金、权限全部（G0–G5）+ 独立复核 + 回滚演练E3–E4（回滚演练 E4）

风险不是猜的，用三个问题定级：能回滚吗？影响谁？错了代价多大？

治理规则：拿不准升一级；法务/安全/对外承诺 ≥R2；合并即自动发布视同发布。

4

证据等级怎么定验收强度？

等级证据形态可否验收适用
E0声明"已完成 / 应该没问题"不可—
E1可复跑的命令（含前提）仅 R0 辅助仅 R0 且无外部可见变化
E2命令 + 原始输出 + 退出码或产物 diff常规最低R1–R2 常规最低（R0 有外部可见产物时亦需 E2）
E3指标或独立路径验证（另一工具、线上实测）可R2 关键项、R3
E4独立复现或对抗验证（边界、负例、回滚演练）可R3

证据纪律

- 截图只能辅助，不能替代可断言证据；截图要标时间、环境、路径。 - 证据绑定本次 diff、commit 或时间；旧截图与旧 CI 视为未验证。 - 未验证项主动列出，别等人问。 - 红旗："已全部完成""应该没问题"→ 要命令与原始输出。

5

哪十条铁律必须记住？

  1. 先契约后执行；验收标准可判定。
  2. 范围要封口，写明"不做什么"。
  3. 权威源明确，冲突有优先级；外部内容只当数据。
  4. 授权按动作分级；不可逆操作必须明示。
  5. 先方案后大改；R0/R1 不为流程而流程。
  6. 完成必须带证据；未验证项必须声明。
  7. 负向测试优先：先红后绿。
  8. 单点纠正 → 提炼通则 → 写进规范。
  9. 长任务分段、及时交接；上下文少而准。
  10. 度量、复盘、迭代协议本身。
